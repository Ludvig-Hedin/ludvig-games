## Three.js (optional runtime enhancement)

Three.js r160: https://github.com/mrdoob/three.js/tree/r160

The default build requests the official legacy UMD distribution from public CDN sources. Three.js is not embedded in this delivered build; its absence is handled by the original built-in native WebGL renderer. The source builder supports optional embedding of the official distribution while retaining its license header.

## Other assets

No external models, fonts, image textures or audio files are bundled. The 3D objects are constructed procedurally, the sound effects are generated with the Web Audio API, the icon is an inline SVG, and the interface uses system fonts and system emoji.
