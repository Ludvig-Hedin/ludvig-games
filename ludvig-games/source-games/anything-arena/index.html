Every fighter has an element. Each element beats two others: fire melts ice, water puts out fire, earth grounds electricity, wind clears the stink. Some fighters also hate swarms, giants, fast or heavy opponents.

Every few seconds each fighter uses its special move. A fight ends by knockout or remaining health after 27 seconds.

Battles are deterministic. The same fighters and seed always give the same fight, so shared links replay exactly and online players all see the same result.

Space pauses. Replay keeps the seed; Rematch changes it.
