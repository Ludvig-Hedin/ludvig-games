# Shared implementation contract

## Engine (`core/game.mjs`, dependency-free ESM)
Exports `COLORS`, `createGame(players, options = {}, rng?)`, `transition(game, playerId, action, rng?)`, `viewFor(game, playerId)`, `chooseBotAction(view, difficulty = 'medium', rng?)`.
Transition is immutable, returns a NEW game or throws `Error` for illegal actions. RNG defaults to unbiased crypto randomness. `createGame` accepts 2–6 players `{id,name,bot,difficulty,avatar}`. Options: `{stacking:false,jumpIn:false,sevenZero:false,quickPlay:false}`. Start from a number card, 7 cards (5 quick play), first player starts. Exact rules documented in RULES.md.
Cards: `{id, color:'red'|'yellow'|'green'|'blue'|'wild', value:'0'..'9'|'skip'|'reverse'|'draw2'|'wild'|'wild4'}`. Action: `{type:'play',cardId,color?,targetId?,call?:boolean}`, `{type:'draw'}`, `{type:'pass'}`, `{type:'call'}`, `{type:'catch',targetId}`. Wild4 only without an active-color card. Default no stacking. Draw one and optionally play only that card; pass after draw. In two-player games Reverse skips. Seven swaps hands with targetId (required); zero rotates hands in the current direction. Final-card call is `CLASH!`; user may pre-arm call on the play leaving one card, or call with one card before caught. Catch costs 2 cards before the next turn action. Seven-zero victory is checked after transfers.
`viewFor` MUST expose only the requesting player's hand and public data, with exact shape:
```
{
 phase:'playing'|'finished', players:[{id,name,bot,difficulty,avatar,count,called}],
 you:string, hand:Card[], currentPlayerId:string, direction:1|-1,
 topCard:Card, activeColor:Color, drawCount:number,
 legalCardIds:string[], canDraw:boolean, canPass:boolean,
 pendingDraw:number, drawnCardId:string|null, winnerId:string|null,
 vulnerablePlayerId:string|null,
 options:{stacking,jumpIn,sevenZero,quickPlay}, turn:number, version:number,
 events:[{id:number,type:string,playerId?:string,card?:Card,amount?:number,color?:string,targetId?:string,text?:string}]
}
```
Engine stores only recent public events, never expose drawn/dealt card identities in events. All consumers use viewFor. AI accepts ONLY view (not game), public counts, its own hand. Optional jump-in allows identical colored face off turn; return legalCardIds even off turn if enabled. chooseBotAction returns one valid action. Core tests own engine correctness, special cards, hidden information, bots and random-match simulation.

## Online API (`server/rooms.mjs` + `app/api/rooms/[[...path]]/route.ts`)
All responses JSON, no-store, errors `{error:string}` with proper status. Reconnect token persisted in localStorage per room; bearer auth via Authorization header. Stable per-player secrets generated by crypto, never include secrets in public room.
POST `/api/rooms` body `{name,avatar,options,difficulty}` => `{code,token,playerId,room}`
POST `/api/rooms/CODE/join` body `{name,avatar}` => `{code,token,playerId,room}`
GET `/api/rooms/CODE` authenticated => `{room}`
POST `/api/rooms/CODE/action` body `{action, expectedVersion,requestId}` => `{room}`
POST `/api/rooms/CODE/start` body `{botCount,difficulty}` host-only => `{room}`
POST `/api/rooms/CODE/rematch` host-only body `{}` => `{room}`
POST `/api/rooms/CODE/leave` body `{}` => `{ok:true}`; in progress departing human replaced by bot; host transfers if needed.
Room public object: `{code,hostId,phase:'lobby'|'playing'|'finished',players:[{id,name,avatar,bot,difficulty?,connected}],options,difficulty,version,game:null|GameView}`.
Server uses D1 `rooms` table and optimistic compare-and-swap version update for all mutations. Authoritative random shuffle and moves. Bots advance one due action per request with a delay (~900ms), derived exclusively from viewFor. Polling GET (every 1.5 s, paused while hidden) drives turns, serializes with CAS. Heartbeat records last seen, reconnection preserves seat/hands. Expire dormant rooms after 24h. Auth required to view hands; wrong/stale versions reject safely. Bounded JSON and user names; length limits; no client-controlled bot or host role; last request ID dedupe per seat. No token in URL.
